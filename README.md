# Cosy Igloo 🧊

Cosy Igloo helps you keep your old-fashioned home warm and save gas. Written in Rust and TypeScript with love, meant to be deployed on Kiwi.

## Installation 🍓

1. Install Docker ([guide](https://docs.docker.com/engine/install/))
1. `docker run --rm -it ghcr.it/eraz1997/cosy-igloo@sha256:<latest-version-hash>
